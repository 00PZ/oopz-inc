# Audience Profiles

Two primary audience segments for content targeting. All agents reference these profiles when calibrating voice, selecting hooks, and choosing content angles. Niche-specific profile skills (e.g., `[[niche-world-mobile]]`) can override or extend these defaults.

## Segment 1: depin-natives

- **Demographics**: 25-40, crypto-literate, likely token holders or node operators, global but concentrated in crypto-active regions
- **Psychographics**: Early adopter mindset, DYOR culture, skeptical of hype, values technical depth and verifiable claims
- **Pain Points**: Tired of vaporware, want signal not noise, frustrated by projects that don't ship
- **Voice Calibration**: Technical, DYOR-respecting, skeptical of hype. Cite sources. Use precise terminology. Avoid "moon" language.
- **Hook Preferences**: Numeric (data-driven), contrarian (challenge mainstream crypto narratives)
- **Taboo Topics**: Price predictions, "guaranteed returns", airdrop farming tips, anything that sounds like financial advice

### Content Guidelines for depin-natives

- Lead with data, architecture, or verifiable milestones.
- Reference on-chain data, GitHub commits, or official documentation when possible.
- Acknowledge risks and trade-offs openly. This audience respects intellectual honesty.
- Use hooks from the Numeric and Contrarian categories in `[[hooks-library]]`.

## Segment 2: connectivity-curious

- **Demographics**: 28-45, tech-forward but not crypto-deep, interested in emerging markets and infrastructure narratives, often in tech/finance adjacent roles
- **Psychographics**: Curious about underserved-market narratives, values social impact framing, open to crypto if the use case is clear
- **Pain Points**: Crypto feels speculative and inaccessible; wants to understand the real-world application
- **Voice Calibration**: Accessible, narrative-driven, personal-stake framing. Explain crypto concepts without jargon. Lead with the human story.
- **Hook Preferences**: Personal-stake (relatable scenarios), curiosity-gap (surprising facts about connectivity gaps)
- **Taboo Topics**: Heavy crypto jargon without explanation, token price focus, anything that alienates non-crypto readers

### Content Guidelines for connectivity-curious

- Lead with the human problem (connectivity gaps, cost, access) before introducing the solution.
- Use analogies and comparisons to familiar concepts (e.g., "like Airbnb but for cell towers").
- Minimize acronyms. When crypto terms are necessary, define them inline.
- Use hooks from the Personal-Stake and Curiosity-Gap categories in `[[hooks-library]]`.

## Cross-Segment Notes

- Most content should target one segment primarily but remain accessible to the other.
- Strategist decides segment targeting per content piece. Writers adapt voice accordingly.
- Analyst tracks engagement metrics per segment to refine these profiles over time.
