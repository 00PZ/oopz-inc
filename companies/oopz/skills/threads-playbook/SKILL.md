## Format Rules

- 500 char limit per post
- Images: up to 10 per post
- No link previews (links work but no preview card)
- Threads: reply chain format (like X threads)

## Cadence

- Target: 2-4 posts/day; max 4/day
- Best times: 09:00-11:00 and 20:00-22:00 Europe/Amsterdam

## Hook Discipline

See `[[hooks-library]]`. On Threads: conversational hot-take hooks dominate. Question-hook and contrarian hooks work well. Lowercase-friendly culture.

## Voice Variant

See `[[brand-voice-system]]`. Threads-specific: conversational, hot-take friendly, slightly more casual than X. Community-first tone. Engage with replies.

## Content-Type Matrix

From `[[content-types]]`: hot-take, community question, contrarian argument, weekly recap, hook-only bait.

## Compliance Overlay

See `[[compliance-rules]]`. On Threads: `#ad` at start of post for sponsored content. For crypto/finance: "Not financial advice. DYOR." as pinned top comment or in post body.

## Native Output Example

```
hot take: the most underrated crypto play isn't a token

it's the infrastructure that makes tokens useful

world mobile is building that infrastructure

not financial advice. dyor.
```
