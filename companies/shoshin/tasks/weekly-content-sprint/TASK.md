Every Monday 10:00 Europe/Amsterdam. This task runs at the Shoshin COMPANY level and **iterates over every niche** listed in `companies/shoshin/COMPANY.md`'s `niches:` frontmatter (Day 1: `[world-mobile]`; add-a-niche = append a slug there, then this task picks it up on the next Monday).

Strategist workflow: (1) read Scout's weekend trend list per niche, (2) for each niche in `company.niches`, select 3-5 topics, (3) for each topic: assign to Researcher (dossier from niche knowledge base and public sources) then Writer (drafts per platform) then Editor (QA gate) then Scheduler (human-in-the-loop queue). Closing criterion: for every niche in `company.niches`, 3-5 approved draft sets queued across the 4 platforms by Wednesday.

> **First-time Paperclip note**: the `company: shoshin` field links this task back to the COMPANY.md file. The niche loop is an EXECUTION pattern described in this body; Paperclip itself does not fan out, the Strategist agent does.
