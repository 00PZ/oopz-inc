## Format Rules

- 280 char limit per tweet; threads split every 250 chars for readability
- No link previews in threads (use link in last tweet or bio)
- Images: 1200x675 (landscape) or 1200x1200 (square)
- Video: up to 2:20, 512MB max

## Cadence

- Target: 3-5 posts/day; max 5/day
- Best times: 08:00-10:00 and 18:00-20:00 Europe/Amsterdam

## Hook Discipline

See `[[hooks-library]]` for full pattern catalog. On X: contrarian and numeric hooks outperform. First 280 chars must hook, no preamble.

## Voice Variant

See `[[brand-voice-system]]` for base settings. X-specific: lowercase casual, contrarian, direct. No corporate filler. Threads feel like a conversation, not a press release.

## Content-Type Matrix

From `[[content-types]]`, best fits for X: thread, hot-take, hook-only bait, contrarian argument, data visualization, weekly recap.

## Compliance Overlay

See `[[compliance-rules]]`. On X: `#ad` in post body AND in bio link for sponsored content. For crypto/finance: "Not financial advice. DYOR." in thread final reply or bio.

## Native Output Example

```
nobody talks about this:

world mobile is building cell towers with crypto incentives

and it's already live in africa

here's why this matters for the next billion users 🧵
```
