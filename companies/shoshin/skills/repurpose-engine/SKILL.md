# Repurpose Engine

## Purpose

The repurpose engine takes ONE idea and produces FOUR platform-native pieces. Not reformatting, rethinking. Each platform has a different culture, attention span, and content contract.

## Input

- Topic + angle (from Strategist queue)
- Target audience segment (from `[[audience-profiles]]`)
- Researcher dossier (facts, claims, sources)

## Process (per platform)

For each platform, ask these rethinking questions:

- **X**: "What's the most contrarian or surprising angle? What would make someone stop scrolling at 2am?"
- **TikTok**: "What's the visual story? What's the verbal hook in the first 3 seconds? What emotion does this trigger?"
- **Instagram**: "What's the visual metaphor? How do I show this, not tell it? What's the carousel arc?"
- **Threads**: "What's the hot take? What would spark a reply? What's the one-sentence version?"

### Rethinking Checklist

Before drafting for each platform, verify:

1. The hook is native to that platform's culture (not transplanted from another draft).
2. The format matches platform conventions (thread for X, vertical video for TikTok, carousel for Instagram, single post for Threads).
3. The angle differs from every other platform's draft for this topic.
4. The call-to-action fits platform norms (retweet vs. save vs. stitch vs. reply).

## Output

Four distinct drafts, each saved to `.evidence/drafts/YYYY-MM-DD-<topic>/<platform>.md`. Each draft loads: `[[x-playbook]]`, `[[tiktok-playbook]]`, `[[instagram-playbook]]`, `[[threads-playbook]]`, `[[hooks-library]]`, `[[brand-voice-system]]`.

### Draft Structure

Each platform draft must contain:

- **Hook**: Selected from `[[hooks-library]]`, adapted to the platform.
- **Body**: Platform-native content (thread posts, script, slide copy, or post text).
- **CTA**: Platform-appropriate call-to-action.
- **Metadata**: Audience segment, hook category used, estimated read/watch time.

## Anti-Pattern

Reformatting = taking the X thread and shortening it for Threads. This is WRONG. Each platform needs its own angle, its own hook, its own format. The topic is the same; the execution is completely different.

### Examples of Reformatting (BAD)

- Copying the X thread intro as the Threads post.
- Taking the TikTok script and reading it over a static image for Instagram.
- Using the same hook across all four platforms.

### Examples of Rethinking (GOOD)

- X thread dissects the technical architecture. TikTok tells the human story of someone affected. Instagram visualizes the before/after. Threads poses the provocative question.
- Same topic, four completely different entry points.
